# Agora-vai-mesmo
# Proteção da Informação

## Projeto Start by Alura

Site educacional desenvolvido para apresentar conceitos de segurança da informação utilizando HTML, CSS e JavaScript.

## Conteúdos abordados

- Criptografia por substituição.
- Cifra de César.
- Codificação e decodificação de mensagens.
- Função hash SHA-256.
- Autenticação segura.
- Combinações de senhas.
- Boas práticas de segurança digital.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Demonstrar, de maneira interativa, como funcionam alguns métodos de proteção de informações e conceitos básicos de segurança digital.

## Autoria

Projeto desenvolvido como atividade educacional da unidade Start by Alura.
